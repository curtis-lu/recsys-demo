dataset pipeline 流程圖

node 層級的 DAG：誰產出什麼、誰吃什麼。對照 src/recsys_tfb/pipelines/dataset/pipeline.py::create_pipeline。 資料表 schema 與跨 pipeline 的完整 lineage 見 data-lineage.html， 各 node 的設定與重跑範圍見 dataset.md。

框內是 node name，可以直接餵給 --from-node / --only-node（--list-nodes 印的也是這個名字）。 它跟函式名不一定相同——四個 build_*_model_input 共用同一個 build_model_input 函式， 對照見下方表格第二欄。刻意不畫：每個 node 都吃的 parameters，以及 enable_calibration: true 才存在的 calibration 分支。

流程圖

左→右為資料流向。三條主線分別是 key 選取（收哪些 row）、前處理（特徵怎麼編碼）、 組裝 model input（把前兩者接起來）。圖寬 1919px，視窗放不下時可在框內左右捲動。

讀圖重點

  • 前處理與抽樣是解耦的。fit_preprocessor_metadata 只吃 feature_table、不吃任何 keys——category mappings 只在 train 月份 fit， 換抽樣設定不會改變編碼結果。
  • 編碼只做一次。apply_preprocessor_to_features 產出的 preprocessed_feature_table 被四個 split 共用，不是每個 split 各編一次。
  • 只有 val / test 會過濾。filter_*_model_input 移除整組沒有正例的 query group， 因為 mAP / NDCG 本來就會排除它們，留著只是浪費儲存與下游記憶體； train / train-dev 的 loss 每一列都會用到，所以不濾。
  • 四個 node 是增量的（圖上標「增量」）： select_test_keys、apply_preprocessor_to_features、 build_test_model_input、filter_test_model_input 只處理尚未落地的月份，差集由 metastore 的 partition 清單得出（零掃描）。 train / train-dev / val 不是增量，每次整批重算。理由與逃生口見 ADR-0002。
  • 閘在最前面。validate_data_consistency 是 Layer-2 資料閘（B1 item coverage、 B5 categorical dtype、B6 非數值特徵欄），只做檢查不產出資料，收集完問題一次中止， 避免抽樣與前處理白跑。

怎麼改這張圖

圖的真實來源是 docs/diagrams/dataset-pipeline.mmd（Mermaid，純文字）。 這頁內嵌的是它渲染出來的 SVG——改圖請改 .mmd，不要直接動這頁的 SVG，否則兩邊會分岔。

# 1. 編輯源檔
vim docs/diagrams/dataset-pipeline.mmd

# 2. 重新渲染（用系統 Chrome，不另外下載 chromium）
cd docs/diagrams
PUPPETEER_SKIP_DOWNLOAD=1 \
PUPPETEER_EXECUTABLE_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
npx -y @mermaid-js/mermaid-cli@10 -t neutral \
  -i dataset-pipeline.mmd -o dataset-pipeline.svg -b transparent

# 3. 把產出的 SVG 內容貼回這頁 <div class="plate"> 之間
#    （width="100%" 改成實際 px、max-width 改 none，文字才不會被縮小）
兩個實測過的坑：(1) .mmd 裡不要留「只有 %%、後面沒有字」的空註解行—— mermaid 不會把它當註解剝掉，會黏成 %%flowchart 然後報 parse error 在第 1 行，很難聯想；要空行就用真正的空行。 (2) 用 mermaid-cli@10 不要用 @11：同一張圖 v11 的新 renderer 產出 666 KB SVG （形狀改由 rough.js 畫，單條 path 灌到 30 KB），v10 是 43 KB。

不想裝工具的話：把 .mmd 全文貼到 mermaid.live， 或貼進任何 .md 的 ```mermaid 區塊讓 GitHub 直接渲染。
